Lambeth Licensing Public Register Scraper
A Python project using Selenium WebDriver to scrape data from the Lambeth Licensing Public Register. This tool automates the extraction of licensing details from multiple pages, allowing users to retrieve and consolidate the information into a structured format for analysis.

Features
Dynamic Page Navigation: Allows scraping across multiple pages by specifying the start and end page range.
Detailed Data Extraction:
Main title and holder name from the search results.
Detailed information from individual license pages, including:
License Type
License Reference Number
License Start Date
License End Date
